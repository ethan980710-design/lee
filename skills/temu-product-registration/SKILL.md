# Temu 오슐랭 상품 등록

## 기본 원칙

- 브랜드는 항상 **오슐랭**이다.
- 먼저 아래 단가 시트의 **테무 단가** 탭에서 A열 값이 `신규등록`인 행만 찾는다.
  - URL: `https://docs.google.com/spreadsheets/d/1PxioDbyAcRxLfzPVqZMtmT9qQzA-mkTgMgrx_4pDoHA/edit?gid=1607678057`
- 처리할 행은 시트 순서상 첫 번째 `신규등록` 행이다. 이미 작업 중인 초안이 있으면 중복 생성하지 말고 그 초안을 이어서 편집한다.
- 상품명은 B열 문구를 띄어쓰기까지 그대로 사용한다.
- 직원에게 동일한 기준을 다시 묻지 말고 아래 규칙으로 진행한다. 단, 상품 고유 정보가 자료로 확인되지 않거나 서로 충돌하면 추정하지 말고 그 항목만 질문한다.
- **제출 버튼은 사용자 승인 전 절대 누르지 않는다.** 제출 직전 초안을 저장한 뒤 알림으로 검토를 요청한다.

## 자료 찾기

- 서버 기준 경로: `\\haeyami\백업용 서버\share02\해야미작업\소셜사이트 작업물`
- 에이전트에서 SMB가 보이지 않으면 WebDAV `http://heyami02.iptime.org:5005/`를 사용한다. 인증정보는 기억이나 스킬에 저장하지 않는다.
- 상품명에 대응하는 폴더를 찾고, `(알리)` 폴더가 있으면 그 자료를 우선한다. 후보가 여러 개면 수정일이 가장 최신인 파일을 사용한다.
- 아래 자료 3종은 필수다.
  1. 상품 상세페이지
  2. 해당 상품의 한글고시라벨
  3. 배송공지, 가능하면 `★공지/상세 하단공지(알리)/알리-상세-하단공지.jpg`
- 한글고시라벨 폴더가 비어 있으면 같은 상품의 정확한 판매 상세에서 라벨을 찾는다. 제품명·중량·원재료가 다른 라벨은 사용하지 말고 확인을 요청한다.
- 배너, 행사 문구, 가격 문구가 들어간 이미지는 대표·캐러셀 이미지에 쓰지 않는다. 상세 이미지에도 일반 광고 배너는 넣지 않는다. 단, 필수 한글고시라벨과 배송공지는 텍스트가 있어도 반드시 포함한다.

## Temu 입력 절차

1. `제품 → 제품 추가 → 빈 양식`으로 빠른 리스팅을 연다.
2. B열 상품명을 입력한다.
3. 자동 추천을 맹신하지 말고 상품에 맞는 식품 카테고리를 직접 선택한다.
   - 건조 오징어류 예시: `식료품&고급식료품 / 육류&해산물 / 해산물 / 건조 해산물 / 말린 오징어`
4. 브랜드 `오슐랭 / 오슐랭`과 등록 상표를 확정한다.
5. 세금 코드를 설정한다.
   - 과세: `GEN_STANDARD`
   - 면세: `GEN_EXEMPT`
   - 확인된 예외: 손질먹태채는 면세다.
   - 처음 보는 식품은 과세 여부를 임의로 추정하지 말고 라벨·상품 자료로 확인하며, 불명확하면 사용자에게 묻는다.
6. 제품 설명은 상품 특징과 용도를 간결하게 작성하고, 원재료·원산지는 상세 이미지 참조라고 안내한다.
7. 제품 캐러셀에는 **텍스트 없는 실제 상품 이미지 1장만** 올린다.
8. 상세 이미지에는 순서대로 상품 상세페이지, 한글고시라벨, 배송공지를 올린다. 긴 상세페이지가 자동 분할되면 업로드 이미지 수와 마지막 라벨·배송공지 노출을 확인한다.
9. 옵션은 상품명에서 확인되는 중량·풍미·구성만 사용한다. 옵션을 적용한 뒤 SKU 행을 만든다.
10. SKU 이미지 창에서 텍스트 없는 실제 상품 이미지를 메인 이미지로 넣는다. 성분·영양정보 이미지가 없으면 `상품상세페이지 참조`를 입력한다.

## 재고·물류

- 판매자 주문 처리 수량: **9,999개**
- 택배 무게:
  - 상품명이 g/kg이면 표시 중량을 그대로 환산해 입력한다.
  - `마리`, `미` 등 개수형이고 실제 중량이 없으면 사용자에게 확인한다.
- 택배 치수: **10 × 10 × 10cm**
- 처리 시간: **영업일 기준 2일**
- 배송 템플릿: SKU 영역과 공급 영역 모두 **무료배송**
- 제품 배송 방법: 일반

## 가격 입력

- J열 값을 SKU의 **기본 가격 입력값**으로 사용한다. I열 값을 기본 가격에 직접 입력하지 않는다.
- 입력 후 화면의 `예상 소매 가격: 다음 이하` 값이 I열 계산 결과와 대응하는지 확인한다. Temu와 시트의 원 단위 표시 방식 때문에 1원 정도 차이가 날 수 있다.
- 정가는 다음 규칙으로 정한다.
  1. 화면의 예상 소매가에 2,000원을 더해 기준값을 만든다.
  2. 기준값과 가장 가까운 **끝자리 900원 가격**으로 조정한다.
  3. 900원 끝자리를 맞추기 위한 차이는 허용한다.
  4. 두 후보가 정확히 같은 거리면 사용자에게 확인한다.
- 예시: 예상 소매가 6,150원 → 기준 8,150원 → 정가 **7,900원**.
- 예시: 예상 소매가 14,072원 → 기준 16,072원 → 정가 **15,900원**.

## 규정 준수

- 가능한 항목은 모두 `상품상세페이지 참조`로 설정한다.
- A/S 담당자 전화번호 또는 소비자 상담 관련 전화번호는 `오슐랭`을 선택한다.
- 원산지는 `상품 상세설명 참조`를 선택한다.
- 수입신고·유전자변형 등 `상품상세페이지 참조` 선택지가 없는 항목은 한글고시라벨에 근거해 선택한다. 근거가 없으면 임의 입력하지 않는다.

## 저장·검토·제출

1. 초안 저장 후 다음을 다시 확인한다.
   - 상품명과 카테고리
   - 오슐랭 브랜드와 과세 코드
   - 캐러셀 텍스트 없는 이미지 1장
   - 상세페이지·한글고시라벨·배송공지
   - SKU 이미지
   - 재고 9,999, 무게, 10×10×10cm
   - J열 기본 가격, 예상 소매가, 900원 끝자리 정가
   - 무료배송 2곳, 처리 2일
   - 규정 준수와 A/S 오슐랭
2. `초안으로 저장` 성공 메시지를 확인한다.
3. 알림으로 상품명과 핵심 입력값을 요약해 사용자 검토를 요청한다.
4. 사용자가 명시적으로 승인하기 전에는 제출하지 않는다.
5. 승인 후 제출하고 생성된 6으로 시작하는 Temu 상품 ID를 확인한다. `가격 평가 중`은 아직 활성 상태가 아니므로 활성 전환을 별도로 확인한다.
6. 제출 성공 후에만 시트 해당 행 A열의 `신규등록`을 Temu 상품 ID로 교체한다. Google Sheets 화면에서 올바른 **테무 단가** 탭과 대상 A셀 값까지 직접 확인한다.
